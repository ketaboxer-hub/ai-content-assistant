# AI Content Assistant v0.1

## Что умеет

Создаёт проекты роликов с названием, идеей и отдельной структурой папок.
Сохраняет и загружает JSON-конфигурации, позволяет изменять идею существующего проекта.
Проверяет обязательные поля, типы значений и пустой ввод.
Обрабатывает повреждённый JSON и ошибки файловых операций.

## Как запустить

Требуется Python 3. Сторонние библиотеки для v0.1 не нужны.
Откройте терминал в папке проекта и выполните:

```powershell
python read_project.py
```
